# -Ai-1-.
피지컬 Ai 기초반 1팀 라즈봇제작

카메라로 화살표·과녁 표지판을 찾아 다가가고, 표지판 앞 25cm에서 신호대로 움직이는 4륜 라즈봇.
단계별 개발 목표는 [PLAN.md](PLAN.md) 참고.

```bash
# 라즈베리파이에서 (~/rasbot)
python3 robot.py --dry-run --save 1   # 바퀴는 멈춘 채 인식·거리·OLED만 확인 (/tmp/rasbot/ 에 1초마다 화면 저장)
python3 robot.py --seconds 15         # 실제 주행 15초 (Ctrl+C 로 언제든 정지)
```

## 1. 동작 메커니즘과 규칙

수치는 모두 `config.py` 의 현재 값이다.

### 하드웨어 구성

| 부품 | 연결 | 하는 일 |
|---|---|---|
| Raspberry Pi 5 (8GB) | – | 모든 판단과 제어 |
| Yahboom Raspbot V2 확장보드 | I2C `0x2B` | 바퀴 4개, 카메라 서보 2개, 초음파 센서 |
| OLED 화면 (128×32) | I2C `0x3C` | 현재 동작 표시 |
| USB 카메라 (2DOF 거치대) | USB | 640×480, 초당 약 15장 |
| 초음파 센서 | 확장보드 경유 | 앞쪽 거리 측정 |

### 전체 흐름

```
 ┌──────────── 찾기 (SEARCH) ◀────────────────────────┐
 │  몸은 멈추고 카메라만 5방향 둘러보기를 반복           │
 │      │ 정면에서 발견          │ 옆에서 발견           │
 │      ▼                       ▼                       │
 │  다가가기 (APPROACH)  ◀── 몸 돌리기 (FACE)            │
 │      │ 정면 + 초음파 25cm 이내                       │
 │      ▼                                              │
 │  실행: ← Left / → Right / ↓ Back / 과녁 Stop ───────┘ (끝나면 다시 찾기)
 │
 └─ 다가가는 중 표지판이 아닌 것이 25cm 안에 있음 → 장애물 대기 (OBSTACLE)
```

### 단계별 규칙

**① 찾기 (`Search`)**
- 몸은 움직이지 않고 카메라 좌우 서보만 돌린다: 정면 → 왼쪽 35° → 오른쪽 35° → 왼쪽 70° → 오른쪽 70°.
- 한 방향마다 흔들림이 멈추길 0.35초 기다린 뒤 0.8초 동안 본다 (한 바퀴 약 6초).
- 못 찾으면 같은 자리에서 계속 반복한다. 보는 범위는 정면 기준 좌우 약 100°이고, 로봇 뒤쪽은 보지 않는다.

**② 몸 돌리기 (`Turn`)**: 옆에서 찾았을 때만
- 돌릴 각도 = 카메라가 돌아간 각도 + 화면 속 표지판 위치 (카메라 시야 65° 기준).
- 회전 시간 = 각도 ÷ 90 × 0.54초. 다 돌면 카메라를 정면으로 되돌리고, 정면부터 다시 확인한다.

**③ 다가가기 (`Approach`)**
- 표지판이 화면 가운데 오도록 좌우 바퀴 속도를 다르게 준다. 화면 가로 ±60%보다 옆이면 전진 없이 제자리에서 돌려 맞춘다.
- 속도: 60cm보다 멀면 보통(70), 60cm 안이면 느리게(40). 초음파 측정이 실패해도 느리게.
- 카메라 위아래 각도가 표지판을 따라간다: 화면 세로 가운데 ±25%를 벗어나면 프레임마다 1°씩 (0~60°).
- 놓쳤을 때: 60cm 밖이면 2초, 60cm 안이면 4초까지 기억한다 (가까워서 화면을 벗어난 경우). 그 시간이 지나면 다시 찾기.

**④ 도착 판정**: 둘 다 만족해야 도착
1. 표지판이 화면 가운데 ±35% 안 (초음파가 표지판을 재고 있다고 믿을 수 있는 조건)
2. 초음파 거리 **25cm 이하**

**⑤ 실행**

| 표지판 | 행동 | OLED |
|---|---|---|
| ← 화살표 | 제자리 왼쪽 회전 0.54초 (≈90°) | `Left` |
| → 화살표 | 제자리 오른쪽 회전 0.54초 | `Right` |
| ↓ 화살표 | 1.5초 후진 | `Back` |
| ↑ 화살표 | 무시 (표지판 앞에서 전진하면 부딪힘) | – |
| 과녁 (또는 GOAL) | 3초 정지 | `Stop` |

**⑥ 반복**: 행동을 마치면 바로 ① 찾기로 돌아간다. 방금 실행한 표지판은 8초 동안 무시한다.

**장애물 (`Obstacle`)**: 다가가는 중 25cm 안에 뭔가 있는데 표지판이 안 보이면 멈춰서 기다린다. 표지판이 다시 보이면 다가가기로, 치워지면(30cm 넘게 비면) 찾기로 돌아간다.

### 인식 방식

**공통: 검은 잉크 찾기**: 각 픽셀을 주변 81px 범위의 평균 밝기와 비교해 15 이상 어두우면 잉크로 본다 (조명이 바뀌어도 종이 대비로 판단).

**화살표** (등록 불필요). 아래를 모두 통과해야 화살표로 인정한다.

| 조건 | 내용 |
|---|---|
| 모양 | 꼭짓점 7개, 그중 오목한 점이 정확히 2개 |
| 구조 | 날개-촉-날개 / 꼬리 2개, 촉이 몸통보다 1.5배 이상 넓음 |
| 테두리 | 곧아야 함 (7각형과 면적 차 12% 이하) |
| 촉 길이 | 촉이 몸통보다 짧음 (빛 반사로 방향을 거꾸로 읽는 것 방지) |
| 밝기 | 안쪽이 고르게 어둡고, 종이보다 40 이상 어둡고, 밝기 비율 0.35 이하 |
| 위치 | 화면 가장자리에 걸려 잘린 모양은 제외 |

방향은 오목한 두 점의 가운데 → 촉 방향으로 계산한다. 이미지 한 장으로 ← → ↓ ↑ 를 모두 구분한다.

**과녁** (등록 불필요): 흰 원 → 검은 고리 → 흰 띠 → 검은 고리 구조를 확인한다. 안쪽 흰 원 반지름을 1로 둔 1.13 / 1.50 / 1.88 위치(원본에서 실측)를 중심에서 16방향으로 보고, 10방향 이상 맞으면 과녁.

**GOAL** (그림 비교): `assets/templates/goal/` 의 이미지와 특징점(ORB)을 비교한다. 인식되면 과녁과 같이 `Stop`.

**표지판 확정**: 최근 5프레임 중 3번 이상 보여야 확정. 카메라를 돌린 직후 0.35초 동안의 흔들린 화면은 쓰지 않는다. 여러 개가 보이면 가장 크게(가깝게) 보이는 것.

### 거리 측정 (초음파)
- 최근 3번 측정값의 중간값을 쓴다.
- 0이거나 400cm를 넘으면 측정 실패로 처리하고, "멀다"고 보지 않는다.

### 안전장치
- 카메라 새 화면이 0.5초 넘게 없으면 바퀴 정지, 5초 넘으면 프로그램 종료.
- 프로그램이 끝나거나 Ctrl+C를 누르면 바퀴 정지, 초음파 끄기, OLED에 `Off` 표시.
- `--dry-run`: 바퀴는 움직이지 않고 인식·거리·화면 표시만 확인.

### 실측해서 맞춘 값

| 항목 | 값 | 근거 |
|---|---|---|
| 90° 회전 시간 | 0.54초 | 0.9초에 약 150°, 바닥에서 확인 |
| 카메라 정면 | 서보 90° | 거치대를 다시 조인 뒤 확인 |
| 카메라 위아래 기본 | 20° | 10°는 약간 아래, 90°는 천장 |
| 카메라 좌우 방향 | 90보다 작으면 오른쪽 | 사진으로 확인 |
| 카메라 시야 | 65° | 실측 60~76° |
| 바퀴 방향 | 4개 모두 정상 | 바퀴를 띄우고 확인 |

### 알려진 한계
1. 과녁은 25cm가 아니라 15~19cm에서 멈춘 경우가 있다 (그 직전 `Obstacle`↔`Approach`를 오감). 화살표는 22~24cm.
2. 로봇 뒤쪽의 표지판은 찾지 못한다.
3. 회전 후 전진하지 않으므로, 다음 표지판은 그 자리에서 보이는 거리(약 1.5m 안)에 있어야 한다.
4. 코팅된 표지판에 빛이 반사되면 인식이 끊길 수 있다 → 무광 종이 권장.
5. 화살표는 종이 가장자리에서 충분히 떨어져 있어야 한다 → `assets/signs/arrow_print.png` (여백 20%)로 인쇄.

## 2. 파일·폴더 구조와 역할

```
RasBot/
├─ robot.py            ★ 메인 주행 프로그램
├─ navigator.py        ★ 주행 판단 규칙
├─ detectors.py        ★ 표지판 인식
├─ hardware.py         ★ 모터·서보·초음파·OLED 제어
├─ config.py           ★ 모든 설정값
├─ vision_demo.py        인식만 확인하는 도구
├─ hw_test.py            부품 점검 도구
├─ make_signs.py         인쇄용 표지판 생성 도구
├─ register_sign.py      그림 표지판(GOAL) 등록 도구
├─ requirements.txt      PC용 파이썬 패키지 목록
├─ README.md             이 문서
├─ PLAN.md               단계별 개발 목표
├─ .gitignore            git에 올리지 않을 파일 목록
├─ assets/               표지판 이미지
│   ├─ originals/        직접 준비한 원본 (화살표, 과녁)
│   ├─ signs/            인쇄용 표지판
│   └─ templates/goal/   GOAL 그림 비교 기준 이미지
├─ models/               손동작 인식 모델 (자동 다운로드, git 제외)
└─ __pycache__/          파이썬 자동 생성 캐시 (git 제외)
```

★ = `robot.py` 실행 시 실제로 쓰이는 파일. 라즈봇에는 `~/rasbot` 에 같은 구조로 복사돼 있다.

### 주행에 쓰이는 핵심 파일

| 파일 | 역할 | 주요 내용 |
|---|---|---|
| `robot.py` | 메인 프로그램. 실행하면 로봇이 움직인다 | 카메라 → 인식 → 거리 → 판단 → 바퀴·카메라·OLED 제어 반복. 카메라는 최신 화면만 쓰도록 따로 읽음. 옵션 `--dry-run`, `--seconds N`, `--save N`, `--show`, `--image` |
| `navigator.py` | 판단 규칙. 지금 상태와 바퀴 속도를 정한다 | 찾기 → 몸 돌리기 → 다가가기 → 도착 → 실행 → 반복, 장애물 대기, 표지판 확정, 8초 무시, 카메라 둘러보기와 위아래 따라가기. 하드웨어와 분리돼 PC에서 시험 가능 |
| `detectors.py` | 인식. 카메라 화면에서 표지판을 찾는다 | 검은 잉크 찾기, 화살표(모양으로 방향 계산), 과녁(고리 구조), GOAL(그림 비교), 손동작(주행에는 미사용). 한글 경로 이미지 읽기/쓰기 |
| `hardware.py` | 하드웨어 제어 | 확장보드(`0x2B`): 바퀴 4개·서보 2개·초음파, OLED(`0x3C`) 글자 표시. 라즈베리파이가 아니면 가짜 하드웨어로 실행(PC 시험용) |
| `config.py` | 설정값 모음. 값을 바꿀 땐 여기만 | 속도, 도착 거리, 회전 시간, 카메라 각도·시야, 둘러보기 순서, 인식 기준값, 무시 시간 등 |

### 도구 파일

| 파일 | 역할 | 사용 예 |
|---|---|---|
| `hw_test.py` | 부품을 하나씩 점검·보정 | `sensor`(초음파), `oled Hello`(화면), `motors`(바퀴 하나씩, **바퀴를 띄우고**), `drive`(전진·후진), `turn --sec 0.54`(90° 회전), `servo 90 20`(카메라 각도), `photo`(사진), `center`(카메라 정면 각도 찾기) |
| `vision_demo.py` | 바퀴 없이 인식만 확인. `robot.py` 가 이 파일의 인식·그리기 기능을 가져다 쓴다 | `python vision_demo.py`, `--image 사진`, `--headless`, `--gesture` |
| `make_signs.py` | 인쇄용 표지판 생성 | GOAL 표지판, 예시 화살표, 여백을 넓힌 우리 화살표(`arrow_print.png`) |
| `register_sign.py` | GOAL 같은 그림 표지판을 사진으로 등록 (화살표·과녁은 등록 불필요) | `python register_sign.py`, `--image 사진` |

### 라즈베리파이 준비 (처음 한 번)

```bash
sudo apt install python3-opencv i2c-tools   # smbus2, Pillow 는 기본 설치
sudo raspi-config nonint do_i2c 0           # I2C 켜기
```
